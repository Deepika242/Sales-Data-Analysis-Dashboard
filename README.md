# Sales Data Analysis and Power BI Dashboard

## Project Overview

This project focuses on cleaning sales data, analyzing business performance, and presenting insights through a Power BI dashboard.

## Technologies Used

* Microsoft Excel – Data cleaning and preprocessing
* Python – Sales data analysis using Pandas
* Google Colab – Running Python code
* Microsoft Power BI – Dashboard visualization
* GitHub – Project source code and documentation

## Key Features

* Sales data cleaning and handling missing values
* Sales and profit analysis
* Regional and category-wise sales analysis
* Monthly sales trend analysis
* Top-performing product analysis
* Interactive Power BI visualizations
* KPI cards for Total Sales, Total Profit, Number of Orders, and Profit Margin

## Project Files

* `Final_cleaned_sales_data.xlsx` – Cleaned sales dataset
* `Internship_Dashboard.pbix` – Power BI dashboard
* `Internship_Sales_Dashboard.png` – Dashboard screenshot
* `intern.ipynb` – Google Colab notebook

## Setup Instructions

1. Download or clone this repository.
2. Open the `.ipynb` notebook in Google Colab.
3. Upload or load the cleaned Excel dataset when required by the notebook.
4. Run the notebook cells to view the sales analysis.
5. Open the `.pbix` file using Microsoft Power BI Desktop to explore the dashboard.
